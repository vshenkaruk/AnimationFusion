# Blocky short project template

Copy this folder into the episode folder created by `python scripts/short_studio.py init`.
Replace `shots.py` with the approved story before running the render pipeline. Use
`kit/API.md` for camera, character, set, action, and prop options.

The renderer exports 1080x1920 H.264 at 60 fps. Set `theme` to `blocky-3d` or
`monochrome` in the generated `timed.json` data. The monochrome grade is applied
after captions are drawn.
